# Atividade BCD

Atividades desenvolvidas durante as aulas de **Banco de Dados (BCD)** utilizando o **MySQL Workbench**.

## Bancos de Dados

* **Concessionaria**

  * Tabela: `veiculos`
  * 10 registros de veículos

* **Biblioteca**

  * Tabela: `livros`
  * 10 registros de livros

* **Escola**

  * Tabela: `alunos`
  * 10 registros de alunos

## Conteúdos trabalhados

* Criação de bancos de dados
* Criação de tabelas
* Definição de campos e tipos de dados
* Chave Primária (Primary Key)
* Auto Increment
* Inserção de registros
* Utilização do MySQL Workbench
